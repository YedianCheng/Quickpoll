# QuickPoll Demo Script

## 🎬 Demo Video Script (5-7 minutes)

### 1. Introduction (30 seconds)
- "Hi, I'm [Your Name] and I'll be demonstrating QuickPoll, a decentralized voting system built on Linera blockchain"
- Show the application running at http://localhost:3000
- Highlight the clean, modern UI

### 2. Wallet Connection (1 minute)
- Click "🔗 Connect Linera Wallet" button
- Show wallet connection process
- Display connected wallet address and chain ID
- Explain the security benefits of wallet-based authentication

### 3. Data Loading (30 seconds)
- Show automatic data loading from blockchain
- Explain how data persists across sessions
- Show the data management panel

### 4. Creating Polls (1.5 minutes)
- Switch to admin role
- Create a new poll: "Should we implement new features?"
- Show the poll creation form
- Demonstrate the blockchain transaction
- Show the poll appearing in the list

### 5. Voting Process (1.5 minutes)
- Switch to user role
- Vote on existing polls
- Show the voting interface
- Demonstrate both YES and NO votes
- Show real-time vote counting
- Explain the blockchain transaction process

### 6. Poll Resolution (1 minute)
- Switch back to admin role
- Resolve a poll with correct answer
- Show the poll status change
- Demonstrate the final results

### 7. Data Persistence (30 seconds)
- Refresh the page
- Show that data is still there
- Explain blockchain storage benefits

### 8. Technical Features (1 minute)
- Show the data management panel
- Display raw blockchain data
- Explain the Linera SDK integration
- Show the GraphQL API working

### 9. Conclusion (30 seconds)
- Summarize the key features
- Mention Linera blockchain benefits
- Call to action for testing

## 🎯 Key Points to Highlight

1. **Decentralized**: No central authority
2. **Transparent**: All votes on blockchain
3. **Secure**: Wallet-based authentication
4. **Persistent**: Data survives page refreshes
5. **Real-time**: Live vote counting
6. **Role-based**: Admin and user permissions

## 📱 Demo Tips

- Use clear, slow movements
- Explain each action
- Show the console logs for technical details
- Highlight the blockchain integration
- Emphasize the user experience

## 🎥 Recording Setup

- **Screen Resolution**: 1920x1080
- **Browser**: Chrome with developer tools open
- **Audio**: Clear narration
- **Duration**: 5-7 minutes maximum
- **Format**: MP4 or webm

## 📝 Demo Checklist

- [ ] Application is running smoothly
- [ ] Wallet connection works
- [ ] Data loads automatically
- [ ] Poll creation works
- [ ] Voting works
- [ ] Poll resolution works
- [ ] Data persists after refresh
- [ ] All features demonstrated clearly
