# QuickPoll 终端交互指南

## 🚀 如何运行演示

### 1. 非交互式演示（推荐先运行这个）
```bash
cargo run --example terminal_demo
```
这个演示会自动展示所有功能，不需要用户输入。

### 2. 交互式演示
```bash
cargo run --example interactive_terminal
```
这个演示允许你通过菜单与系统交互。

## 📋 功能说明

### 支持的操作：
1. **创建投票** - 创建新的投票问题
2. **投票** - 对现有投票进行赞成/反对投票
3. **解决投票** - 管理员可以结束投票并设置正确答案
4. **查看投票列表** - 查看所有投票的状态和结果
5. **帮助** - 显示系统帮助信息
6. **退出** - 退出程序

### 使用示例：

#### 创建投票
- 选择选项 1
- 输入投票问题，例如："你认为 Rust 是最好的编程语言吗？"
- 输入结束时间（秒），默认 86400（24小时）

#### 投票
- 选择选项 2
- 输入投票 ID（从创建投票的响应中获取）
- 选择 1=赞成 或 0=反对
- 输入投票金额，默认 100

#### 解决投票
- 选择选项 3
- 输入要解决的投票 ID
- 输入正确答案（1=赞成，0=反对）

#### 查看投票列表
- 选择选项 4
- 系统会显示所有投票的详细信息

## 🔧 技术特点

- **基于 Linera 区块链框架**
- **支持 GraphQL 查询**
- **类型安全的 Rust 实现**
- **异步处理支持**

## 🎯 使用场景

- **社区治理投票** - 社区决策投票
- **预测市场** - 用户可以预测事件结果
- **民意调查** - 收集公众意见
- **决策支持系统** - 帮助组织做出决策

## 🛠️ 开发说明

### 项目结构
```
src/
├── lib.rs          # ABI 定义
├── state.rs        # 数据结构和状态
├── contract.rs     # 合约逻辑
└── service.rs      # GraphQL 服务

examples/
├── demo.rs                    # 简单演示
├── simple_demo.rs            # 详细演示
├── terminal_demo.rs         # 非交互式终端演示
└── interactive_terminal.rs   # 交互式终端演示
```

### 运行测试
```bash

cargo test --test single_chain
```

### 编译检查

## 📝 注意事项

1. **交互式演示**：如果程序出现死循环，请按 `Ctrl+C` 停止
2. **输入验证**：程序会验证输入的有效性
3. **数据持久性**：当前演示版本的数据在程序结束后会丢失
4. **错误处理**：程序包含基本的错误处理机制

## 🎉 开始使用

1. 首先运行非交互式演示了解功能：
   ```bash
   cargo run --example terminal_demo
   ```

2. 然后尝试交互式演示：
   ```bash
   cargo run --example interactive_terminal
   ```

3. 按照菜单提示进行操作

## 💡 提示

- 这是一个演示版本，实际部署需要 Linera 区块链环境
- 所有操作都是模拟的，不会真正影响区块链状态
- 可以多次运行程序来测试不同场景
